## 阅读源码的方法

本阶段按设计问题阅读源码，不按文件顺序从头讲到尾。先用一个可运行的小程序复现行为，再带着问题读对应版本的实现，最后回到服务的内存、延迟或吞吐指标。运行时内部结构会随 Go 版本改变；本书示例中的源码观察以 Go 1.23 为基准，涉及后续实现变化时会标明边界。
